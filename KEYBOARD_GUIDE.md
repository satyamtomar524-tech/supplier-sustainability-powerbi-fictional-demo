# Keyboard interaction

Use Ctrl+F6 between application sections, Tab/Shift+Tab within a section, and arrows/Enter on page tabs. Ctrl+Right enters a selected visual; Escape exits a layer. Desktop authoring mode also exposes formatting controls.

In Supplier Evidence, enter the selected slicer with Ctrl+Right, then use arrows and Enter/Space. Ctrl+Space and Shift+Down/Shift+Space were tested and kept one selected workshop. Home/Enter returns to the first workshop. Use Overview for multiple-label comparisons.

The Technology selector replaces its ordinary-click selection; its clear icon restores all labels. The Overview table can filter its cards by selected row. Every visual has an accessibility description, with heading-first tab order. These are functional checks, not a spoken screen-reader audit or accessibility certification. No drillthrough, chart or custom tooltip page exists.
